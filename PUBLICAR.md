# Como publicar este repositório no GitHub

Comandos prontos para colar. Substitua `SEU-USUARIO` pelo seu usuário do GitHub.

## 1. Crie o repositório no GitHub
Acesse https://github.com/new e crie um repositório **público** chamado, por exemplo,
`requirements-engineering-portfolio`. **Não** marque "Add a README" (já temos um).

## 2. No terminal, dentro desta pasta

```bash
git init
git add .
git commit -m "Portfolio de engenharia de requisitos (bilingue, anonimizado)"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/requirements-engineering-portfolio.git
git push -u origin main
```

## 3. Pronto
Seu portfólio estará em:
`https://github.com/SEU-USUARIO/requirements-engineering-portfolio`

## Dica: fixar no perfil
No seu perfil do GitHub, clique em "Customize your pins" e fixe este repositório
para que ele apareça no topo.

## Dica: link no LinkedIn
Adicione o link do repositório na seção "Destaques" ou "Sobre" do LinkedIn.

---

**Lembrete de anonimização:** este repositório foi gerado com os clientes
generalizados (sem nomes), pensado para ser público e permanente. Se algum dia
quiser uma versão com nomes para uso privado (ex.: enviar direto a um recrutador),
mantenha-a fora do GitHub público.
