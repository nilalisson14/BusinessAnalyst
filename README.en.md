## About this repository

A collection of **real, anonymized cases** from my career, organized by area of competency. Each case describes context, scope, applied skills, and outcome, without exposing sensitive client data.

> **Anonymization note:** clients are referred to generically (e.g., "health regulatory agency", "state-owned energy company"). Names of people, credentials, endpoints, identifiers, and operational data have been removed. Any data in examples is fictional. This is a deliberate professional-confidentiality choice for a public repository.
